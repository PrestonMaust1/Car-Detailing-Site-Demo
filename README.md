# Summit Auto Detailing — Interactive Portfolio Demo

Dark, animated, responsive fictional auto-detailing website built with HTML/CSS/JavaScript. Includes mobile navigation, touch-friendly controls, small-screen layouts, and reduced-motion support.

## Interactive features
- Car showcase with pointer-parallax motion on desktop
- Clickable accent-lighting controls (lime, blue, violet, red)
- Scroll-triggered reveal animations
- Interactive image reveal slider (artistic comparison, not literal before/after)
- Service tabs swap copy, sample prices, included features, and images
- Click-to-enlarge gallery with Escape/click-to-close
- Mobile navigation
- Demo quote form opens an email draft only

## Run on Mac
1. Unzip the archive.
2. Open the extracted folder in VS Code.
3. Open `index.html` in Safari/Chrome. Optional: use the VS Code Live Server extension.
4. Internet is needed for photos and web fonts. No build step is required.
5. To check the mobile layout on your Mac, open the page in Chrome and choose View → Developer → Developer Tools, then click the phone/tablet device icon. Also test on a real phone after publishing.

## Publish free with GitHub Pages
1. Create a GitHub repository named `summit-auto-detailing-interactive`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Repository Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Wait for the published URL to appear in Pages settings.

## Important
- Summit Auto Detailing is fictional. Keep the demo label visible until a real business owner authorizes a client version.
- Prices and package descriptions are examples, not actual offers.
- Images load from Unsplash URLs; verify terms and replace with licensed/client-authorized photos before commercial use.
- The form opens an email draft to `hello@example.com`; it does not submit or store information.
